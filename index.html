เข้าใจประเภทรองเท้า โปรแกรมซ้อม และรูปเท้า

1) ประเภทรองเท้าวิ่ง

Recovery Day

ใช้สำหรับ: วันพักฟื้นหลังซ้อมหนัก

ลักษณะเด่น: นุ่มมาก รองรับแรงกระแทก

เหมาะกับ: คนที่อยากให้ขาได้พัก

ควรใช้: วันวิ่งเบามากหรือเดินเร็ว

Easy Run

ใช้สำหรับ: วิ่งสบายๆ พูดคุยได้

ลักษณะเด่น: นุ่มและเบาพอดี ใช้ได้หลายแบบ

เหมาะกับ: มือใหม่ทุกคน

ควรใช้: ซ้อมประจำวันส่วนใหญ่

Long Run

ใช้สำหรับ: วิ่งระยะไกลเพิ่มความอึด

ลักษณะเด่น: นุ่ม เด้ง มั่นคง

เหมาะกับ: คนเริ่มซ้อมระยะไกล

ควรใช้: วิ่งยาวสุดสัปดาห์

Tempo

ใช้สำหรับ: วิ่งเร็วสม่ำเสมอ

ลักษณะเด่น: เบา ตอบสนองดี

เหมาะกับ: คนที่อยากเร็วขึ้น

ควรใช้: วันซ้อมความเร็ว

Race Day

ใช้สำหรับ: วันแข่งจริง

ลักษณะเด่น: เบามาก แรงส่งสูง

เหมาะกับ: คนที่ต้องการทำเวลา

ควรใช้: วันแข่งหรือทดสอบเวลา

2) อธิบายโปรแกรมการวิ่ง

Recovery Day

จุดประสงค์: ให้ร่างกายฟื้นตัว

ความหนักเบา: เบามาก

เหมาะกับ: ทุกคน

ตัวอย่าง: เช่น วิ่งช้าหรือเดินเร็วหลังวันที่หนัก

Easy Run

จุดประสงค์: สร้างพื้นฐานความอึด

ความหนักเบา: เบา (พูดเป็นประโยคได้)

เหมาะกับ: มือใหม่

ตัวอย่าง: เช่น วิ่ง 3–5 กม. ช้าๆ

Long Run

จุดประสงค์: เพิ่มความทนทานระยะไกล

ความหนักเบา: เบาถึงปานกลาง

เหมาะกับ: คนที่เริ่มวิ่งได้ต่อเนื่อง

ตัวอย่าง: เช่น ค่อยๆ เพิ่มระยะทีละนิดสัปดาห์ละครั้ง

Tempo

จุดประสงค์: ฝึกวิ่งเร็วต่อเนื่อง

ความหนักเบา: ค่อนข้างหนัก

เหมาะกับ: คนที่วิ่งได้สม่ำเสมอแล้ว

ตัวอย่าง: เช่น วิ่งเร็วขึ้นช่วงกลางของการวิ่ง

Race Day

จุดประสงค์: ทดสอบเวลาจริง

ความหนักเบา: หนัก

เหมาะกับ: คนที่ลงแข่ง

ตัวอย่าง: เช่น งานวิ่ง 5 หรือ 10 กม.

3) เลือกรองเท้าตามรูปเท้า

เท้ากว้าง

ลักษณะ: ปลายเท้ากว้างกว่าปกติ

ปัญหาที่พบ: เจ็บบีบด้านข้าง เล็บช้ำ

ควรเลือก: เลือกรุ่นหน้ากว้างหรือ wide

ควรระวัง: อย่าซื้อไซซ์ใหญ่เพื่อแก้ ควรเลือกทรงที่กว้างพอ

เท้าแบน

ลักษณะ: อุ้งเท้าต่ำ

ปัญหาที่พบ: เมื่อยเท้า ปวดอุ้งเท้าได้

ควรเลือก: รองเท้ามั่นคง ซัพพอร์ตดี

ควรระวัง: เลี่ยงพื้นบิดง่ายมาก

เท้าล้มใน (Overpronation)

ลักษณะ: ข้อเท้าล้มเข้าด้านในตอนก้าว

ปัญหาที่พบ: ปวดเข่าหรือหน้าแข้งได้

ควรเลือก: รองเท้าเน้นความมั่นคง

ควรระวัง: ควรลองวิ่งจริงหรือปรึกษาร้านวิ่ง

4) สรุปสำหรับมือใหม่

วิ่งช้า สบายๆ
